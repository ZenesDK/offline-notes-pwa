## Описание проекта

Прогрессивное веб-приложение (PWA) для управления заметками с поддержкой:
- **WebSocket (Socket.IO)** — двусторонняя связь в реальном времени между клиентами
- **Push-уведомления** — оповещения даже при закрытом приложении
- **Офлайн-режим** — работа без интернета
- **Установка на устройство** — как нативное приложение

### Что добавлено в ПЗ №16

| Компонент | Описание |
|-----------|----------|
| **Node.js сервер** | Express + Socket.IO + web-push |
| **WebSocket** | Мгновенные уведомления между вкладками |
| **Push-уведомления** | Системные уведомления через Service Worker |
| **VAPID ключи** | Для идентификации сервера при push |
| **Управление подписками** | Включение/отключение уведомлений |

## Установка и запуск

### Требования

- Node.js (версия 16 или выше)
- npm (версия 8 или выше)

### Установка зависимостей клиента

```bash
git clone <ссылка-на-репозиторий>
cd notes-app
npm install
npm install socket.io-client
```

### Установка зависимостей сервера

```bash
cd server
npm init -y
npm install express socket.io web-push cors
```

### Генерация VAPID ключей

```bash
npx web-push generate-vapid-keys
```

**Пример вывода:**
```
Public Key: BG7tQ...
Private Key: tRX9M...
```

**Важно:** Сохраните эти ключи — они понадобятся в коде сервера!

### Настройка сервера

Отредактируйте `server/server.js`, вставив свои VAPID ключи:

```javascript
const VAPID_PUBLIC_KEY = 'ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ';
const VAPID_PRIVATE_KEY = 'ВАШ_ПРИВАТНЫЙ_КЛЮЧ';
```

### Сборка клиента и запуск

```bash
# В корневой папке проекта
npm run build

# Запуск клиента (production режим)
npm run preview -- --host 0.0.0.0
```

### Запуск сервера (в отдельном терминале)

```bash
cd server
node server.js
```

**Ожидаемый вывод:**
```
🚀 Сервер запущен на http://localhost:3001
📢 VAPID Public Key: BG7tQ...
```

### Открытие приложения

1. Откройте `https://localhost:4173`
2. Нажмите **"Включить уведомления"** и разрешите браузеру показывать уведомления
3. Откройте **вторую вкладку** с тем же адресом
4. В первой вкладке добавьте заметку

## API сервера

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| POST | `/api/subscribe` | Сохранить push-подписку |
| POST | `/api/unsubscribe` | Удалить push-подписку |
| GET | `/api/vapid-public-key` | Получить публичный VAPID ключ |
| WebSocket | `newTask` | Отправка события о новой заметке |
| WebSocket | `taskAdded` | Получение события о новой заметке |

## Service Worker (push обработчик)

```javascript
// Обработчик push-уведомлений
self.addEventListener('push', (event) => {
  let data = { title: 'Новая заметка!', body: '' };
  if (event.data) {
    data = event.data.json();
  }
  event.waitUntil(
    self.registration.showNotification(data.title, {
      body: data.body,
      icon: '/icons/favicon-128x128.png',
      badge: '/icons/favicon-48x48.png',
      vibrate: [200, 100, 200]
    })
  );
});

// Обработчик клика по уведомлению
self.addEventListener('notificationclick', (event) => {
  event.notification.close();
  event.waitUntil(
    clients.openWindow('/')
  );
});
```

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| WebSocket не подключается | Проверьте, что сервер запущен (`node server.js`) |
| Push не работает | Убедитесь, что сайт открыт по HTTPS (`https://localhost:4173`) |
| Ошибка CORS | В server.js есть cors() — должно работать |
| Не приходят уведомления между вкладками | Проверьте консоль браузера на ошибки WebSocket |
| VAPID ключи недействительны | Сгенерируйте новые: `npx web-push generate-vapid-keys` |
