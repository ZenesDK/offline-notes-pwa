## Описание проекта

Прогрессивное веб-приложение (PWA) для управления заметками с расширенным функционалом напоминаний:

- ⏰ **Создание заметок с напоминанием** (выбор даты и времени)
- 🔔 **Push-уведомления** в заданное время
- ⏱️ **Откладывание напоминаний** на 5 минут (кнопка в уведомлении)
- 📡 **WebSocket** — уведомления в реальном времени между вкладками
- 📱 **Установка на устройство** (PWA)
- 💾 **Офлайн-режим**

### Что добавлено в ПЗ №17

| Компонент | Описание |
|-----------|----------|
| **Форма с datetime-local** | Выбор даты и времени напоминания |

| **Планирование на сервере** | `setTimeout` для отправки push в заданное время |
| **Хранилище reminders** | `Map` с активными таймерами напоминаний |
| **Кнопка "Отложить"** | В push-уведомлении (action: 'snooze') |
| **Эндпоинт /api/snooze** | Откладывание напоминания на 5 минут |

## Установка и запуск

### Требования

- Node.js (версия 16 или выше)
- npm (версия 8 или выше)

### Установка зависимостей клиента

```bash
git clone <ссылка-на-репозиторий>
cd notes-app
npm install
npm install socket.io-client
```

### Установка зависимостей сервера

```bash
cd server
npm init -y
npm install express socket.io web-push cors
```

### Генерация VAPID ключей

```bash
npx web-push generate-vapid-keys
```

**Пример вывода:**
```
Public Key: BG7tQ...
Private Key: tRX9M...
```

**Важно:** Сохраните эти ключи — они понадобятся в коде сервера!

### Настройка сервера

Отредактируйте `server/server.js`, вставив свои VAPID ключи:

```javascript
const VAPID_PUBLIC_KEY = 'ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ';
const VAPID_PRIVATE_KEY = 'ВАШ_ПРИВАТНЫЙ_КЛЮЧ';
```

### Сборка клиента и запуск

```bash

# Запуск клиента (production режим)
npm run preview -- --host 0.0.0.0
```

### Запуск сервера (в отдельном терминале)

```bash

```

**Ожидаемый вывод:**

## Использование напоминаний

### Создание заметки с напоминанием

1. В разделе **"⏰ Заметка с напоминанием"** введите текст
2. Выберите дату и время (должно быть в будущем)
3. Нажмите **"Добавить с напоминанием"**

### Что происходит

1. Заметка сохраняется в `localStorage` с полями:
   - `reminder` — timestamp выбранного времени
   - `reminderId` — уникальный идентификатор
   - `reminderText` — текст напоминания

2. Клиент отправляет событие `newReminder` на сервер через WebSocket

3. Сервер создаёт `setTimeout` на указанное время

4. В назначенное время сервер отправляет push-уведомление

5. В уведомлении появляется кнопка **"Отложить на 5 минут"**

6. При нажатии на кнопку отправляется запрос на сервер (`/api/snooze`)

7. Сервер отменяет старый таймер и создаёт новый на 5 минут

## API сервера (добавлено в ПЗ №17)

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| WebSocket | `newReminder` | Получение напоминания от клиента |
| POST | `/api/snooze` | Откладывание напоминания на 5 минут |

### Событие newReminder (WebSocket)

```javascript
socket.emit('newReminder', {
  id: 'note-id',
  reminderId: 'reminder_1234567890_abc123',
  text: 'Купить молоко',
  reminderTime: 1745433600000  // timestamp
});
```

### Запрос на откладывание

```javascript
fetch('/api/snooze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ reminderId: 'reminder_1234567890_abc123' })
});
```

## Service Worker (добавлено в ПЗ №17)

### Обработчик push с кнопкой "Отложить"

```javascript
self.addEventListener('push', (event) => {
  const data = event.data.json();
  const options = {
    body: data.body,
    icon: '/icons/favicon-128x128.png',
    badge: '/icons/favicon-48x48.png',
    data: { reminderId: data.reminderId }
  };
  
  // Добавляем кнопку только для напоминаний
  if (data.reminderId) {
    options.actions = [
      { action: 'snooze', title: '⏰ Отложить на 5 минут' }
    ];
  }
  
  event.waitUntil(
    self.registration.showNotification(data.title, options)
  );
});
```

### Обработчик клика с действием "snooze"

```javascript
self.addEventListener('notificationclick', (event) => {
  const action = event.action;
  const reminderId = event.notification.data?.reminderId;
  
  if (action === 'snooze' && reminderId) {
    event.waitUntil(
      fetch('/api/snooze', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ reminderId })
      })
    );
  }
  
  event.notification.close();
});
```

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Напоминание не приходит | Проверьте, что сервер запущен и VAPID ключи правильные |
| Кнопка "Отложить" не появляется | Убедитесь, что в push-уведомлении передан reminderId |
| После откладывания уведомление не приходит | Проверьте консоль сервера, должен быть лог "Напоминание отложено" |
| Напоминание приходит сразу после создания | Проверьте, что выбранное время в будущем |
