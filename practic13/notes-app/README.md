## Описание проекта

Веб-приложение для управления заметками с поддержкой офлайн-режима через Service Worker. Приложение позволяет создавать, просматривать, редактировать и удалять заметки, сохраняя их в `localStorage`. При отсутствии интернета все функции остаются доступными благодаря кэшированию статических ресурсов.

## Установка и запуск

### Требования

- Node.js (версия 16 или выше)
- npm (версия 8 или выше)

### Установка зависимостей

```bash
git clone <ссылка-на-репозиторий>
cd notes-app
npm install
```

### Режим разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### Production сборка и запуск

```bash
npm run build
npm run preview
```

Приложение будет доступно по адресу: `http://localhost:4173`

## Тестирование офлайн-режима

### Способ 1: Через DevTools (рекомендуемый)

1. Запустите production версию: `npm run build && npm run preview`
2. Откройте `http://localhost:4173`
3. Нажмите **F12** → вкладка **Application** → **Service Workers**
4. Отметьте чекбокс **"Offline"**
5. Обновите страницу — она должна загрузиться из кэша
6. Попробуйте добавить/редактировать/удалить заметки — всё работает

### Способ 2: Физическое отключение сети

1. Запустите production версию
2. Отключите Wi-Fi или интернет-кабель
3. Обновите страницу — приложение продолжает работать

## Проверка Service Worker

### В Chrome/Chromium

1. **F12** → **Application** → **Service Workers**
   - Статус: `activated and running`
   - Scope: `http://localhost:4173`

2. **F12** → **Application** → **Cache Storage**
   - Должны быть кэшированы: `index.html`, `sw.js`, иконки и др.

3. **F12** → **Application** → **Local Storage**
   - Ключ: `notes` — содержит JSON с заметками

### В Firefox

1. **F12** → **Storage** → **Service Workers**
2. **F12** → **Storage** → **Cache Storage**
3. **F12** → **Storage** → **Local Storage**

## Структура Service Worker

```javascript
// public/sw.js
const CACHE_NAME = "notes-pwa-v1";
const STATIC_ASSETS = ["/", "/index.html", ...];

// Установка — кэширование ресурсов
self.addEventListener("install", ...);

// Активация — очистка старых кэшей
self.addEventListener("activate", ...);

// Fetch — Network First стратегия
self.addEventListener("fetch", ...);
```

### Стратегия кэширования: Network First

1. Сначала пытается загрузить ресурс из сети
2. При успехе — сохраняет в кэш
3. При ошибке (нет сети) — возвращает из кэша
4. Если нет ни в сети, ни в кэше — возвращает fallback страницу

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Страница не открывается офлайн | Запустите `npm run build && npm run preview` (не `npm run dev`) |
| Service Worker не регистрируется | Проверьте, что файл `public/sw.js` существует |
| Иконки не отображаются | Проверьте пути в `manifest.json` |
| Заметки не сохраняются | Проверьте `localStorage` в DevTools |
